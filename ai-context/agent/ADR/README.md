# Architecture Decision Records (ADRs)

This directory contains the architectural decisions that define AI Context Generation itself.

Unlike the generated `AI-Context`, which documents a target repository, these ADRs document the design principles, constraints, and long-term decisions of AI Context Generation.

Every architectural change to this project should be recorded as a new ADR.

Existing ADRs should never be modified to represent a new decision. Instead, create a new ADR that supersedes the previous one whenever necessary.
